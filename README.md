## Features Implemented

### 1. Sticky Header

The sticky header is hidden by default and smoothly slides down when the user scrolls past the hero section. It disappears again when scrolling back to the top. The header includes a glass-blur background effect and smooth transition animation.

### 2. Image Carousel with Zoom

The hero section includes an interactive image carousel with four product images. Users can navigate using previous and next arrow buttons, or click the thumbnail strip below to jump to a specific slide. The carousel also supports touch and drag on mobile devices.

On hovering over the carousel, a magnified zoom preview panel appears and tracks the cursor position, giving users a closer look at the image. The same zoom feature is applied to each card in the Applications section carousel.

### 3. Responsive Design

The page is fully responsive and works across desktop (1440px), tablet (900px), and mobile (600px) screen sizes. CSS Grid and Flexbox are used throughout the layout. On mobile, the navigation collapses into a hamburger menu with an animated toggle.

## Technical Details

- HTML — Semantic HTML5 elements with ARIA labels for accessibility
- CSS — CSS custom properties, Flexbox, Grid, transitions, and media queries
- JavaScript — IntersectionObserver for the sticky header, pointer events for drag and touch support, and a modular IIFE structure
- No external libraries or frameworks used
- Compatible with Chrome, Firefox, Safari, and Edge
