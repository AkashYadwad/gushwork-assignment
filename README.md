## ✅ Features Implemented

### 1. Sticky Header
- Appears smoothly when the user scrolls past the hero section
- Hides when scrolling back to the top
- Glass-blur background effect
- Smooth slide-down transition animation

### 2. Image Carousel with Zoom
- Interactive hero carousel with 4 product images
- Previous / Next arrow navigation
- Thumbnail strip for direct slide selection
- Touch / drag support for mobile
- **Zoom feature** — hovering over the carousel shows a magnified preview panel that tracks the cursor position
- Application section carousel with the same zoom on each card

### 3. Responsive Design
- Fully responsive across desktop (1440px), tablet (900px), and mobile (600px)
- CSS Grid and Flexbox used throughout
- Mobile hamburger menu with animated toggle

---

## 🛠️ Technical Details

- **HTML** — Semantic HTML5 elements with ARIA labels for accessibility
- **CSS** — CSS custom properties, Flexbox, Grid, transitions, media queries
- **JavaScript** — IntersectionObserver for sticky header, pointer events for drag/touch, modular IIFE structure
- No external libraries or frameworks used
- Cross-browser compatible (Chrome, Firefox, Safari, Edge)
